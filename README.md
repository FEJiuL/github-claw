# 🦞 github-claw — 个人 AI 助手工作空间

这个仓库是**个人 AI 助手长期驻留的工作空间**，基于 OpenClaw 理念设计。

AI 助手在这里不只是回答问题，而是持续做事、积累记忆、维护角色，让这个仓库逐渐成为一个可长期演化的个人 AI 空间。

## 📂 目录结构

```
github-claw/
├── AGENTS.md          # 👤 角色定义与工作规范
├── MEMORY.md          # 🧠 长期记忆和重要发现
├── README.md          # 📖 本文件（工作空间入口）
├── memory/
│   └── DAILY.md       # 📝 日志与临时记录
├── docs/              # 📚 知识库和技术文档
├── projects/          # 🚀 长期项目
├── tasks/             # ✅ 单次任务
└── src/               # 💻 代码实验和工具
```

## 🧠 核心概念

### 文件即记忆
所有信息持久化到仓库文件中，不依赖对话历史。每次新对话都能从文件恢复上下文。

### 记忆分层
- **长期记忆** → `MEMORY.md`：重要决策、项目状态、技能清单
- **短期记忆** → `memory/DAILY.md`：日志与临时记录
- **临时记忆** → 对话本身：当前会话中的工作上下文

## 🔄 工作流程

```
对话开始
    ↓
读取 AGENTS.md + MEMORY.md + memory/DAILY.md
    ↓
理解任务和上下文
    ↓
执行：搜索、分析、创建、修改
    ↓
记录：更新 memory/DAILY.md 和相关文件
    ↓
提交：一个原子性的 Git 提交
    ↓
对话结束
```

## 🚀 如何使用

1. 在新的 GitHub Copilot 对话中，打开这个仓库
2. AI 助手会自动读取 `AGENTS.md`、`MEMORY.md`、`memory/DAILY.md`
3. 告诉助手你要做什么
4. 助手会执行任务并记录更新

## ✅ 核心特性

- ✅ 角色清晰 — AGENTS.md 定义了角色、能力、工作流程
- ✅ 持久记忆 — MEMORY.md + memory/DAILY.md 记录决策和日志
- ✅ 工作规范 — 每次对话都有清晰的收尾清单
- ✅ 跨对话工作 — 下次打开仓库 URL 即可自动恢复上下文
- ✅ 轻量可扩展 — 可根据需要添加 docs/、projects/ 等目录
