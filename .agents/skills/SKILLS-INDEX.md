## 📝 技能管理说明

### 表格字段说明
- **技能名称** — 技能的正式名称（英文，用连字符分隔单词）
- **目录** — 技能文件在 `.agents/skills/` 中的路径
- **描述** — 技能的一句话概述
- **安装来源** — GitHub URL、Skills.sh URL 或"内部开发"
- **安装时间** — 技能安装或最后更新的日期（YYYY-MM-DD 格式）
- **状态** — `活跃`、`维护中`、`已弃用`
- **使用次数** — 该技能被使用的总次数（定期更新）

### 状态定义
- **活跃** — 定期使用，运行良好
- **维护中** — 已安装但使用较少，可能需要优化
- **已弃用** — 不再使用，但保留文件供参考

## 🔄 使用工作流

### 安装新技能
1. 选定技能后，创建目录：`mkdir -p .agents/skills/<skill-name>/`
2. 将技能文件（SKILL.md 及支持文件）复制到目录
3. 在本表格中添加一行记录
4. 更新 `memory/DAILY.md`，记录技能安装信息

### 使用技能
1. 从本表格找到技能名称
2. 打开对应目录下的 `SKILL.md`
3. 按照 SKILL.md 中的工作流执行任务
4. 使用完成后，更新本表的"使用次数"

### 更新技能
1. 编辑 `.agents/skills/<skill-name>/SKILL.md`
2. 更新安装时间为当前日期
3. 在 `memory/DAILY.md` 中记录更新内容
4. 提交更改

### 弃用技能
1. 将状态改为"已弃用"
2. 在 `memory/DAILY.md` 中记录弃用原因
3. **不删除文件**，保留历史参考
