# 技能：网络调研 (Web Research)

## 能力描述
对指定主题进行系统性网络搜索和信息整理，输出结构化的调研报告。

## 适用场景
- 技术选型调研
- 竞品分析
- 最佳实践查询
- 问题排查与方案调研
- 行业动态跟踪

## 前置条件
- 明确调研主题和目标
- 知道搜索关键词或方向

## 执行步骤
1. **明确需求** — 确认调研范围、深度和输出格式
2. **初步搜索** — 使用 WebSearch 获取概览信息
3. **深度挖掘** — 对关键结果使用 WebFetch 获取详细内容
4. **交叉验证** — 对比多个来源，评估信息可靠性
5. **整理输出** — 将调研结果写入 `docs/research/` 目录

## 输出规范
- 调研报告路径：`docs/research/[主题英文名].md`
- 报告格式：摘要 → 方法 → 发现 → 结论 → 参考来源
- 在 `MEMORY.md` 中记录关键发现（如果需要长期记忆）
- 在 `memory/DAILY.md` 中记录耗时和任务摘要

## 示例报告结构
```markdown
# 调研：[主题名称]

## 摘要
[一句话说明调研结论]

## 调研方法
[搜索关键词、数据来源等]

## 关键发现
- [发现1]
- [发现2]

## 结论与建议
[总结和建议]

## 参考来源
- [URL1]
- [URL2]
```

## 注意事项
- 优先使用官方文档和第一手来源
- 区分事实和观点
- 注明信息获取时间（可能过时）
- 对于代码示例，尽量验证其可用性
