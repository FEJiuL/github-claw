# 🛠️ 技能目录 (Skills Catalog)

技能是 Claw 可复用的能力模块。每个技能定义了一种特定的工作方式、工具链和输出规范。

## 技能系统说明

技能系统让 Claw 能够：
- **模块化工作** — 每种任务有标准化的执行流程
- **持续进化** — 可根据需要添加新技能
- **质量保障** — 每种技能有明确的输入和输出规范

## 如何使用技能

1. 用户提出任务后，Claw 识别需要哪些技能
2. 读取对应技能文件获取详细操作指南
3. 按照技能规范执行任务
4. 在 `memory/DAILY.md` 中记录技能使用情况
5. 如需新增技能，创建新的技能文件并更新本目录

## 技能模板

创建新技能时请使用以下模板：

```markdown
# 技能：[技能名称]

## 能力描述
[简要说明这个技能能做什么]

## 适用场景
- [场景1]
- [场景2]

## 前置条件
- [需要的文件、工具或信息]

## 执行步骤
1. [步骤1]
2. [步骤2]

## 输出规范
- [输出的位置和格式]

## 示例
[简单示例]
```

## 可用技能清单

| 技能 | 描述 | 文件 |
|------|------|------|
| 网络调研 | 对指定主题进行系统性搜索和信息整理 | `skills/web-research.md` |
| 代码审查 | 审查 Pull Request 或代码片段的质量和安全性 | `skills/code-review.md` |
| 文档写作 | 编写结构化的技术文档和使用说明 | `skills/doc-writing.md` |

## 技能管理规则

- 每个技能文件独立存放在 `skills/` 目录
- 技能文件命名：`skills/[技能英文名].md`
- 新增技能后立刻更新本目录的"可用技能清单"表格
- 过时技能标记为"已归档"而非删除

## 技能状态

- 🟢 **就绪** — 技能已定义并可用于任务
- 🟡 **草稿** — 技能定义中，尚未完成
- 🔴 **待定** — 技能已提出但未实现
